problem: "Natural Resources Canada publishes a table of every energy R&D project it funds, recipient, program, dollars, technology. Public, but just HTML. No API, no export."
moves: "Connected Claude to Notion through MCP (Model Context Protocol), an open standard that lets a model call a tool's real actions instead of hand-wiring an integration, then had it read the live page, normalize the fields (typed dates, locations, currency) and write every row straight into a Notion database."
result: "233 rows became one live, filterable database: $709M CAD tracked across 10 programs, filterable by program, province and technology."
ai: "The agent read an external source and operated a real tool accurately enough to trust with the data entry itself. No scraper, no script, no copy-paste."
